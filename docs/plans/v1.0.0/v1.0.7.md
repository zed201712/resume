# 規劃 v1.0.7 (Refined)

## 更新目標
1. 修復日文語系下 `HeroSection` 的問候語句法，並將實作方式重構為更具擴展性的 **「翻譯佔位符 (Placeholders)」** 方案。
2. 在日文模式下，於姓名後方加上「です」，並確保語法銜接處（空格）符合在地化習慣。
3. 姓名保持強調色（Primary Color），而問候語的前綴與後綴使用一般文字顏色。

## 執行細節

### 1. 翻譯檔案更新 (`assets/translations/*.json`)
將原本拆分的邏輯整合為完整的句子模板，利用 `{name}` 作為佔位符：
- **`en.json`**: `"heroGreeting": "Hello, I am {name}"`
- **`zh.json`**: `"heroGreeting": "你好，我是 {name}"`
- **`ja.json`**: `"heroGreeting": "こんにちは、私は{name}です"`

### 2. UI 組件修改 (`lib/ui/widgets/sections/hero_section.dart`)
採用解析翻譯字串的方式，實現不同段落的不同樣式：
- 使用 `tr(namedArgs: {"name": "NAME_HOLDER"})` 取得模板。
- 透過 `split("NAME_HOLDER")` 將字串拆分為前綴 (Prefix) 與後綴 (Suffix)。
- 在 `RichText` 中分別建立三個 `TextSpan`：`Prefix` -> `resumeData.name` (強調色) -> `Suffix`。

## 預計修改代碼片段 (`HeroSection`)
```dart
// 獲取帶有佔位符的翻譯字串
final greetingTemplate = "heroGreeting".tr(namedArgs: {"name": "NAME_HOLDER"});
final parts = greetingTemplate.split("NAME_HOLDER");
final prefix = parts[0];
final suffix = parts.length > 1 ? parts[1] : "";

// ... 
RichText(
  text: TextSpan(
    style: GoogleFonts.notoSansTc(
      fontSize: isMobile ? 36 : 60,
      fontWeight: FontWeight.w900,
      color: const Color(kTextColor),
      height: 1.1,
    ),
    children: [
      TextSpan(text: prefix),
      TextSpan(
        text: resumeData.name,
        style: const TextStyle(
          color: Color(kPrimaryColor),
        ),
      ),
      if (suffix.isNotEmpty) TextSpan(text: suffix),
    ],
  ),
),
```

## 驗證計畫
1. 切換至 **日文**：檢查是否顯示為「こんにちは、私は[姓名]です」，且中間無空格。
2. 切換至 **英文**：檢查是否顯示為「Hello, I am [姓名]」，且維持原有空格。
3. 確保姓名顏色高亮在所有語系中均正常運作。
