# v1.0.2 Bio 內嵌區塊導向按鈕實作計劃

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 在 HeroSection 的 bio 內容中，針對工作經歷與作品摘要，分別加入可跳轉至對應區塊的連結按鈕。

**Architecture:** 
1. 修改 `ResumeData` 的 bio 字串結構，使用 `\n\n` 分隔不同區塊。
2. 修改 `HeroSection` 接收導向回調（Callbacks）。
3. 在 `HeroSection` 內部分析 bio 並插入 `_LinkButton` 元件。

**Tech Stack:** Flutter, LucideIcons, easy_localization, provider

---

## Task 1：更新資料模型與內容存取

**Files:**
- Modify: `lib/utils/constants.dart`

**Step 1：調整 bio 內容結構**
將 `resumeDataZh`, `resumeDataEn`, `resumeDataJa` 的 bio 欄位，統一改為由三個 `\n\n` 分隔的區塊：
1. 自我介紹 / 學歷
2. 工作經歷摘要
3. 個人作品 / AI 技術應用摘要
