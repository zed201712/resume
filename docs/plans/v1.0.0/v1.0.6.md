# 規劃 v1.0.6

## 更新目標
1. 在 `Project` 模型中新增 `aspectRatio` 屬性，以便針對各個專案動態調整顯示比例。
2. 更新 UI `ProjectsSection` 中的 `GridView.builder` 邏輯，在構建之前提取最小的 `aspectRatio`，並將其設定為 `childAspectRatio`。
3. 更新常量設定，為所有語言的專案增加 `aspectRatio: 0.5` 的初始值。

## 執行細節
* **修改 `lib/models/resume_model.dart`**：
  - 在 `Project` class 中新增了 `final double aspectRatio;` 屬性。
  - 在 constructor 的參數中加入了 `required this.aspectRatio`。
* **修改 `lib/ui/widgets/sections/projects_section.dart`**：
  - 透過 `reduce` 語法找出 `resumeData.projects` 當中的最大 `aspectRatio`，作為網格的基本設定 (`childAspectRatio: maxAspectRatio`)，防止佈局異常。
* **修改 `lib/utils/constants.dart`**：
  - 更新 `resumeDataZh`, `resumeDataEn`, `resumeDataJa` 底下所宣告的所有 `Project` (`p1`, `p2`)，分別帶入 `aspectRatio: 0.5` 參數。
