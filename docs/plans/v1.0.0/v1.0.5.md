# 規劃 v1.0.5

## 更新目標
1. 針對 `lib/utils/constants.dart` 內的 `resumeDataZh` 中新增的專案 `p1` (民宿網站系統升級)，改用本地端資源。
2. 更新 UI 呈現邏輯，讓專案組件能同時兼容網路圖片 (URL) 與本地端圖片 (Asset)。
3. 將新增的專案 `p1` 同步更新至 `resumeDataEn` 與 `resumeDataJa` 的英文與日文版履歷結構中以維持多語言同步。

## 執行細節
* **修改 `lib/ui/widgets/sections/projects_section.dart`**：
  - 增加影像路徑前綴檢查邏輯 (`startsWith('http')`)，若是 URLs 維持使用 `Image.network`，反之使用 `Image.asset` 來讀取專案圖片。
  - 對於空圖片路徑增加 fallback 屬性 (顯示內建圖示與預設背景)，提供防錯機制與一致性的 UI 體驗。
* **修改 `lib/utils/constants.dart`**：
  - 為 `resumeDataEn` 補上 id 為 `p1` 的英文版專案資料 (Guesthouse Website System Upgrade)。並將原本的遊戲專案 id 更正為 `p2`。
  - 為 `resumeDataJa` 補上對應的日文版專案資料 (ゲストハウスWebシステムアップグレード)。
  - 統一三個語系中 `p1` 專案圖片路徑皆設定為 `assets/images/project_001_icon.png`。
