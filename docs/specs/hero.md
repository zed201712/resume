# Hero 區塊

依序顯示：問候語、職稱、三段自我介紹；旁邊是個人照片（手機時排在下方）。

## 問候語

翻譯檔 `heroGreeting` 是含 `{name}` 佔位符的完整句子，讓各語言自行決定姓名位置：

| 語言 | 模板 |
|---|---|
| 中文 | `你好，我是 {name}` |
| 英文 | `Hello, I am {name}` |
| 日文 | `こんにちは、私は{name}です` |

姓名以主色顯示，前後文字為一般文字色。

## 自我介紹

`ResumeData` 的三個欄位依序顯示：

| 欄位 | 內容 | 下方按鈕 |
|---|---|---|
| `introBio` | 自我介紹 / 學歷 | 無 |
| `experienceBio` | 工作經歷摘要 | `navExperience` 文字 + 箭頭，捲動到工作經歷區塊 |
| `projectBio` | 個人作品摘要 | `navProjects` 文字 + 箭頭，捲動到專案展示區塊 |

三段不合併成單一字串。
