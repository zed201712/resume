# v1.0.1 Bug 修復設計文件

**日期**: 2026-03-03
**版本**: v1.0.1
**類型**: Bug 修復

---

## 背景

v1.0.0 完成後發現兩個 UX 問題：

1. 手機端 (<768px) Navbar 完全隱藏，導致無法切換語言也無法跳轉 section
2. `ProjectsSection` 的點擊觸發區域過小（僅 "View Details" 文字），在觸控裝置上難以操作

---

## Fix 1：手機 Navbar 適配

**檔案**: `lib/ui/screens/home_screen.dart`

### 問題

```dart
if (MediaQuery.of(context).size.width >= 768)
  Row(children: [...navButtons, _LanguageSwitcher()])
// 手機端：什麼都不顯示
```

手機寬度 <768px 時，整個 Row（含語言切換器）消失。

### 解決方案

在現有 `if` 區塊加 `else` 分支，顯示 icon 版導覽 + 語言切換器：

```dart
if (size.width >= 768)
  Row(children: [...text nav buttons..., _LanguageSwitcher()])
else
  Row(
    mainAxisSize: MainAxisSize.min,
    children: [
      IconButton(icon: Icon(LucideIcons.user, size: 20),     onPressed: () => _scrollToSection(_heroKey)),
      IconButton(icon: Icon(LucideIcons.zap, size: 20),      onPressed: () => _scrollToSection(_skillsKey)),
      IconButton(icon: Icon(LucideIcons.briefcase, size: 20), onPressed: () => _scrollToSection(_experienceKey)),
      IconButton(icon: Icon(LucideIcons.code, size: 20),     onPressed: () => _scrollToSection(_projectsKey)),
      const SizedBox(width: 8),
      _LanguageSwitcher(),
    ],
  )
```

**Icon 對應**：

| Section | Icon |
|---------|------|
| About (Hero) | `LucideIcons.user` |
| Skills | `LucideIcons.zap` |
| Experience | `LucideIcons.briefcase` |
| Projects | `LucideIcons.code` |

**樣式**：
- Icon 顏色：`Color(0xFF475569)` (Slate 600)，與桌面 `_NavButton` 一致
- Icon 大小：20px
- 不加 Tooltip（空間有限）

## Fix 2：ProjectCard 整體可點擊

**檔案**: `lib/ui/widgets/sections/projects_section.dart`

### 問題

```dart
// 只有 hover overlay 內的 InkWell 可點擊
AnimatedOpacity(
  opacity: _isHovered ? 1.0 : 0.0,  // 手機沒有 hover
  child: InkWell(
    onTap: () => launchUrl(...),
    child: Text(tr('projectsViewDetails')),  // 觸控區域極小
  ),
)
```

觸控裝置無 hover 狀態，overlay 永遠不可見；即使在桌面，文字點擊範圍也太小。

### 解決方案

在 `_ProjectCardState.build()` 最外層加 `GestureDetector`：

```dart
GestureDetector(
  onTap: () => launchUrl(Uri.parse(widget.project.link)),
  child: MouseRegion(
    // 現有結構完全不變
    child: AnimatedContainer(...),
  ),
)
```

**效果**：
- 整張卡片（圖片區 + 文字區）皆可點擊
- 桌面 hover overlay 視覺效果保留
- `launchUrl` 邏輯與原 `InkWell` 相同，不重複
