# 專案概覽 (Project Overview)

本專案是一個基於 Flutter 開發的個人履歷/作品集網站，具備多語言支持、現代化 UI 設計以及 AI 互動功能。

## 畫面功能與對應檔案

以下是本專案的主要畫面功能、用途及其對應的 Dart 實作檔案：

+-----------------------+-------------------------------------------------------+-------------------------------------------------+
| 畫面/功能             | 用途                                                  | 對應檔案                                        |
+-----------------------+-------------------------------------------------------+-------------------------------------------------+
| 核心框架 (Main Screen)| 應用程式進入點，管理導航列、語言切換與整體佈局            | lib/ui/screens/home_screen.dart                 |
+-----------------------+-------------------------------------------------------+-------------------------------------------------+

## 關鍵決策與限制 (Key Decisions & Constraints)

*   **AI 助手開發狀態**: 目前專案中雖然有 `AiAssistantWidget` 與 `ChatProvider` 相關檔案，但計畫中**尚未包含**其功能實作。AI 助手目前僅作為 Mock 展示，不具有讀取履歷資料或呼叫 API 的實質邏輯。
*   **Bio 資料結構**: 自 `v1.0.3` 起，履歷資料的 Bio 被拆分為 `introBio`, `experienceBio`, `projectBio`，並且目前**沒有**合併為一個單一字串 (如 `fullBio`) 的需求。

> [!IMPORTANT]
> 後續開發請勿針對 AI 助手功能進行多餘的檢查或主動規劃其邏輯串接方案，除非使用者明確提出要求。

## 技術規範

*   **框架**: Flutter (Web/Desktop/Mobile)
*   **狀態管理**: Provider
*   **語系支持**: easy_localization (zh, en, ja)
*   **設計風格**: Modern, Responsive, Glassmorphism
