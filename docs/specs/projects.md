# 專案展示

## 網格

| 區塊寬度 | 欄數 |
|---|---|
| > 1024 | 3 |
| > 768 | 2 |
| 其他 | 1 |

每個 `Project` 有 `aspectRatio`；網格的卡片比例取所有專案中**最小**的值（卡片最高者），讓每張卡片都放得下內容。沒有專案時為 0.8。

## 卡片

- 上方為圖片，下方為標題、描述（最多 10 行）與技術標籤。
- **整張卡片可點擊**，開啟 `Project.link`（觸控裝置沒有 hover 也能操作）。
- 桌面 hover 時卡片上浮、標題變主色，圖片上顯示「查看詳情」遮罩。

## 圖片來源

| `Project.image` | 顯示 |
|---|---|
| 以 `http` 開頭 | 網路圖片 |
| 其他非空字串 | 本機資源（如 `assets/images/...`） |
| 空字串 | 預設圖示與灰底 |
